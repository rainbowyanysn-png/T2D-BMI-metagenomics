# Original input acquisition

The frozen inputs are provider resources retrieved through curatedMetagenomicData3.16.1
and exact ExperimentHub IDs, not copied historical analysis outputs. See
config/source_resources.csv, config/package_input_objects.csv and data_manifest.csv.
Provider caches may contain the original downloadable resources; their exact hashes
are checked. No prepared R workspace or manually copied derived object is required
for a fresh run. Observe the provider/source-study access and licensing terms.
